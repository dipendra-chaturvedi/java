# Java

* JDK = Java Development Kit
```
JDK
 ├── javac    → Java compiler
 ├── java     → Runs Java programs
 ├── javadoc  → Generates documentation
 └── other development tools
```

## Compile to run process
```
              COMPILE
.java ───────────────────→ .class
                              │
                              │ JVM
                              ↓
                           Program
```
